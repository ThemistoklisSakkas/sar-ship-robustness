# Dataset licences

The datasets themselves are never committed to this repository.

## SSDD (official release)

- Source: https://github.com/TianwenZhang0825/Official-SSDD (Google Drive / Baidu links in README)
- Licence: the official repository is published under **Apache-2.0**. The README does not
  state separate terms for the image data; we treat the data as covered by that release
  and comply with the authors' explicit request to cite the paper below.
- Required citation:
  T. Zhang et al., "SAR Ship Detection Dataset (SSDD): Official Release and Comprehensive
  Data Analysis," *Remote Sensing*, vol. 13, no. 18, Art. no. 3690, 2021.
  https://doi.org/10.3390/rs13183690
- Limitation: the underlying satellite scenes come from several sensors with their own
  original data policies; SSDD is used here for research/non-commercial purposes only.
